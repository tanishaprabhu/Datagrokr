CLI Grade Calculator: 
A simple Python-based command-line Grade Calculator that manages student marks, calculates averages and grades, and stores results in a CSV file.

Features
1. Add and search students
2. Calculate total, average & grade
3. Save/read results using CSV
4. Handle invalid inputs

Concepts : Lists, Tuples, Sets, Dictionaries, Loops, Functions, Strings, CSV and Exception Handling.

Technology : Python
