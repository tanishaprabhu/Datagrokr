# SQL E-commerce

A SQL project focused on analyzing e-commerce data and extracting business insights.

## Project Overview
This project includes 35+ SQL queries covering product performance, customer spending, NULL handling, joins, aggregation, subqueries, views, and database constraints.

## Project Files
- `01_schema.sql` — Creates the database tables and defines the schema.
- `02_seed_data.sql` — Inserts sample e-commerce data.
- `03_queries.sql` — Contains the analysis and practice queries.

## How to Run
1. Open MySQL Workbench or another MySQL-compatible SQL client.
2. Run `01_schema.sql` to create the database and tables.
3. Run `02_seed_data.sql` to insert sample records.
4. Run `03_queries.sql` to execute the analysis queries.

The scripts use MySQL syntax. Some statements may need adjustment for other database systems.

## Topics Covered
- Joins and aggregate functions
- Customer spending and product sales analysis
- NULL handling with `IS NULL` and `COALESCE`
- Filtering, grouping, and sorting
- Subqueries, `CASE`, and views
- Primary keys, foreign keys, and check constraints
