Week 3 - ETL Pipeline Project : This project implements a simple ETL (Extract, Transform, Load) pipeline using Python.

The pipeline:
1. Extracts user data from a REST API.
2. Transforms the JSON data using Pandas.
3. Loads the transformed data into a CSV file.
4. Uses Pytest to test the ETL functions.

Technologies Used

- Python
- Requests
- Pandas
- Pytest
- REST API
- CSV
